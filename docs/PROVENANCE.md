# Provenance and credits

R3Neer directs the project, specifies gameplay, selects and critiques designs,
and performs human playtesting. An OpenAI coding agent contributed substantial
implementation, tests, documentation, translations, concepts and final artwork.

The native 16 x 16 sprites were drawn pixel by pixel in Piskel through computer
use operated by the AI agent. Editable originals and lossless clipboard exports
are in `art/piskel`. This describes the production method, not human authorship.
AI-generated concept images informed the designs but are not bundled in the JAR.
Generated rotations, charge composites and extruded geometry derive from those
AI-authored Piskel masters. Screenshots are actual Minecraft captures.

Minecraft assets are referenced by resource identifier, not copied into this mod.
Minecraft is owned by Mojang/Microsoft; this is not an official Minecraft product.

p1kl's 3D Items is an external, optional resource pack. The mod's original model
body uses its measured 9 x 9 x 2 dimensions for visual consistency. The bridge
detects upstream resources but does not redistribute the upstream ZIP, models or
textures. The release does not include Alex's Mobs, FrozenLib or other optional
dependencies. Registry checks and resource tags provide those integrations.

The repository retains its GPL-3.0-only license. Corresponding source is available
in the tagged repository and sources JAR. Existing license notices are preserved.
